# 故障排查

## 双击 start-windows.vbs 后没有打开页面

1. 手动访问 `http://127.0.0.1:8765`。
2. 查看 `logs/server.log`。
3. 双击 `start-windows.bat` 查看可见错误。
4. 检查 `runtime\windows-python\pythonw.exe` 是否存在。

纯 Windows 启动器不依赖 WSL。只有使用兼容入口 `start-kb.vbs` 失败时，才在 Windows 终端运行：

```powershell
wsl.exe --cd "<项目所在的 Windows 路径>" bash -lc "python3 run.py"
```

## 页面显示“连接中断”或 502

WSL 代理可能错误代理了 localhost。本项目的 Python 健康检查和 Windows 启动器已显式绕过代理。若浏览器仍受代理扩展影响，请把 `127.0.0.1` 和 `localhost` 加入“不使用代理”列表。

## 端口 8765 被占用

修改 `config.json` 的 `port`，并同步修改四个启动文件中的本地 URL：`start-windows.vbs`、`start-windows.bat`、`start-kb.vbs`、`start-kb.bat`。

也可先关闭占用该端口的旧实例，再重新启动。

## 新目录或文件没有出现

- 目录或文件必须位于 `library/` 内，支持任意深度；
- 以 `.` 开头的目录会被忽略；
- `.tmp`、`.part`、`.crdownload`、`.lnk` 被忽略；
- 等待配置中的刷新间隔（默认约 5 秒）；
- 查看 `logs/server.log` 是否出现“索引已更新”。

## 悬浮说明没有显示

- 推荐文件名为 `_说明.md`；
- 支持 `_说明.md`、`_meta.md`、`说明.md`、`README.md`；
- 触屏设备没有鼠标悬浮，请进入对应目录查看本级说明；
- 说明文件应保存为 UTF-8；
- YAML 头信息的开头和结尾必须是单独一行 `---`。

## 悬浮说明太长，无法滚动

- 桌面端可把鼠标从知识卡片移入悬浮说明窗，再用滚轮或右侧滚动条阅读完整内容；
- 卡片与悬浮窗之间保留了短暂的离开宽限时间，正常移动鼠标时窗口不会立即关闭；
- 鼠标同时离开卡片和悬浮窗后，说明窗才会自动关闭；
- 手机、触屏设备或需要键盘完整阅读时，进入对应目录查看当前目录说明区。

## 文件操作没有反应

- 先点击文件名，确认文件仍然存在；
- “默认应用”使用 Windows 当前文件关联；没有默认关联时系统会返回明确错误；
- “选择应用…”调用 Windows 原生“选取应用”，并自动激活任务栏中的对应按钮；正常情况下应直接显示选择窗口，不需要手动点任务栏，也不应出现 PowerShell 终端；
- “所在位置”会打开资源管理器并**选中目标文件**，不是只进入“文档”或父目录；Windows 可能复用已有资源管理器窗口；
- 文件名可使用中文、空格和 `&`，但应避免控制字符和极端超长路径；
- 查看 `logs/server.log` 中的“默认打开”“选择应用”“打开所在文件夹”记录；
- 浏览器查看不等于原生打开：Office 文件通常应使用“默认应用”或“选择应用”。

如果“选择应用”再次只闪任务栏，先关闭旧的“选取应用”实例后重试；不要同时连续点击多次。若自动激活脚本失效，可在可见 PowerShell 中单独运行 `src\activate_open_with.ps1` 排查，但日常启动不会显示该终端。

## 页面样式没有更新

服务已发送禁止缓存响应。若浏览器仍保留旧样式，按 `Ctrl+F5` 强制刷新。

## stop-windows.vbs / stop-windows.bat 提示拒绝停止

`stop.py` 会检查 PID 是否确实属于本项目，避免误杀其他进程。纯 Windows 模式只接受两种身份：命令行中带参数边界的精确 `<当前项目>\run.py`，或相对 `run.py` 配合 `<当前项目>\runtime\windows-python\` 下的专用解释器；不会把 `LocalKnowledgeBase-copy` 等同名前缀目录误判为当前项目。WSL 兼容模式通过 `/proc` 核对。仍有问题时检查端口和进程命令行，不要直接按 PID 强制结束不明程序。

## 中文显示为方框

Windows 10/11 浏览器通常自带“Microsoft YaHei UI”。这一问题主要可能发生在精简 Linux 环境，安装 `Noto Sans CJK SC` 后即可。项目 CSS 已包含两种字体回退。
