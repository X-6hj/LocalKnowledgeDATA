# 使用手册

## 1. 启动与停止

- 推荐启动：双击项目根目录的 `start-windows.vbs`，使用项目自带的 Windows 便携 Python，后台运行且不显示命令窗口。
- 页面地址：`http://127.0.0.1:8765`。
- 推荐停止：双击 `stop-windows.vbs`。
- 排错备用：`start-windows.bat` / `stop-windows.bat` 会显示控制台过程。
- 如果浏览器没有自动打开，可手动访问上述地址。

纯 Windows 启动不要求安装 WSL，也不要求系统预装 Python。已有 WSL 的电脑可继续使用兼容入口 `start-kb.vbs` / `stop-kb.vbs`，但不要与纯 Windows 实例同时启动。

## 2. 建立多级目录

`library` 下支持任意深度目录，不再限制为“一级分类、二级条目”。例如：

```text
library/
└─ 算法/
   ├─ _分类.md
   ├─ 数论/
   │  ├─ _说明.md
   │  ├─ 质数/
   │  │  ├─ _说明.md
   │  │  ├─ 埃氏筛.html
   │  │  ├─ 埃氏筛.md
   │  │  └─ 埃氏筛.cpp
   │  └─ 最大公约数/
   │     └─ 欧几里得.cpp
   └─ 图论/
      └─ 最短路径/
```

- 一级目录用于根索引，可以放 `_分类.md` 自定义名称、图标、摘要和顺序。
- 任意目录都可以继续建立子目录。
- 文件放在哪一级，就显示为该级目录的“直属文件”。
- 保存后等待最多约 5 秒，页面会重新扫描整棵目录树并自动更新。

## 3. 为每级目录添加说明

任意目录均可放置 `_说明.md`：

```markdown
---
title: 数论
summary: 整数性质及其计算方法。
tags: [算法, 数论]
pinned: false
order: 100
entry: 埃氏筛.html
---

这里写本级目录的完整说明。
```

支持的目录说明文件名按优先级为：`_说明.md`、`_meta.md`、`说明.md`、`README.md`，推荐统一使用 `_说明.md`。

`entry` 是可选首选入口，只能填写本目录中的直属文件名。系统按以下规则选择：

1. `_说明.md` 中有效的 `entry`；
2. 否则选择本目录按名称排序后的第一个 `.html` / `.htm`；
3. 没有 HTML 时不显示首选入口。

显式 `entry` 可以指向其他格式，此时按钮显示“打开首选资料”。不得在 `entry` 中填写子目录、绝对路径或 `../`。

一级目录还支持 `_分类.md` / `_category.md`。一级目录同时存在 `_分类.md` 与 `_说明.md` 时：

- `_说明.md` 的同名字段优先；
- `_说明.md` 没写的 `icon`、`order` 等字段继续使用 `_分类.md`；
- 正文优先显示 `_说明.md` 正文。

## 4. 逐级浏览

- 首页只显示 `library` 的一级目录。
- 点击目录卡片的“进入目录”，只显示该目录的直属子目录。
- 页面顶部面包屑显示当前位置，例如“知识库 › 算法 › 数论”；点击任意一级即可返回。
- 进入目录后，“当前目录”区域显示该级说明和直属文件。
- 该目录存在 `primary_file` 时，会在完整文件列表上方显示醒目的首选入口；点击 HTML 入口会在新标签页打开学习笔记。
- 左侧根目录索引可从任意深度快速切换到某个一级目录。
- 桌面端把鼠标移到任意目录卡片上可查看该目录说明；长说明可以把鼠标移入悬浮窗后滚动。
- 手机或触屏设备不显示悬浮窗，可进入目录查看说明和直属文件。

## 5. 搜索、筛选与收藏

- 顶部搜索是全库搜索，会查找目录显示名、文件夹路径、摘要、正文、标签和直属文件名。
- 搜索结果可以直接命中任意深度目录，不受当前位置限制。
- 文件格式筛选按整个目录子树判断；例如 CPP 位于“算法/数论/质数”，根目录“算法”也会命中 CPP 筛选。
- 星标收藏的是目录节点，收藏保存在当前浏览器中。
- “最近更新”和“按名称”只改变当前结果顺序。
- 按 `/` 可快速聚焦搜索框；“清除全部筛选”会返回知识库根目录。

## 6. 查看和打开文件

- HTML 学习页建议由 `templates/学习笔记.html` 起步，并统一引用 `/static/note.css`；它支持桌面、手机、深浅色和打印。
- HTML 只是首选阅读界面，不替代 Markdown、CPP、PDF 等源资料；它们仍在下方完整显示。
- 点击文件名：由浏览器查看或下载；PDF、图片、文本通常可直接预览。
- 点击文件旁的“打开⌄”：可选择“默认应用”“选择应用…”或“所在位置”。
- “默认应用”：调用 Windows 当前默认程序。
- “选择应用…”：弹出 Windows 原生“选取应用”。
- “所在位置”：打开资源管理器并选中目标文件。
- 所有文件操作都先经过 `library` 路径边界检查。

## 7. 新建题目学习页

推荐结构：

```text
算法大类 / 可复用题型 / 题号 - 题名 - 核心知识描述/
├─ _说明.md
├─ 题名 - 核心方法.html
├─ 题名 - 核心方法.md
└─ 题名.cpp
```

- HTML 是精心设计的首选复习页，强调记忆锚点、关键推导、代码对应和易错点，不粘贴冗长原题解。
- 有 AC 代码时，HTML 同时展示关键函数讲解、完整 AC 代码和整份程序的执行流程。完整代码与 CPP 保持一致；整体讲解不重复函数区已经说明的细节。
- Markdown 是易编辑、可检索的备用文本版；无法渲染数学公式时使用可直接阅读的纯文本公式。
- 用户提供的 AC 代码原样保留，不为了“统一风格”擅自重写，也无需重复测评。
- 每个新 HTML 都要按 `docs/HTML学习笔记设计规范.md` 单独设计和验收，不能只替换模板标题与正文。

## 8. 删除、移动与重命名

直接在资源管理器中删除、移动或重命名目录和文件即可。页面会自动更新路径、父子关系、统计和面包屑。为避免复制到一半时出现短暂的半成品目录，建议整组资料复制完成后再改为最终目录名。

目录路径决定节点 ID。重命名或移动目录后，浏览器会把它视为新目录，因此该目录原有的本地收藏需要重新添加。

## 9. 备份

最简单的备份方式是复制整个项目根目录（目录名不限）。真正重要的数据都在 `library` 中；至少要备份该目录。不要只备份页面或索引而遗漏原始资料。
