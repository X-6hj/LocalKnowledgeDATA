## 已知说明

无头 Chromium 会把自己报告为“无悬浮设备”，因此浏览器测试时模拟了有鼠标环境来覆盖悬浮分支；真实 Windows 鼠标环境会直接触发。当前推荐运行方式是纯 Windows 便携 Python；WSL 只作兼容。所有原生文件操作先经过 `library` 路径边界检查，系统选择器激活会短暂移动鼠标到任务栏按钮并在约 80 ms 后恢复原位置。
