适合计算机基础课程尚未系统学习、准备进入大二，希望以计算机网络为主线，同时学习 Linux、操作系统和数据结构的学习者。

路线从 TCP Echo 热身开始，依次完成分层网络诊断工具、多人 TCP 聊天室和 Mini HTTP 服务器，并包含技术选型、阶段验收、测试方法、AI 辅助开发规则和十二周进度建议。

建议按阶段实践，不要一次性生成完整项目；每个功能都应实际编译、运行、抓包、调试并记录复盘。
