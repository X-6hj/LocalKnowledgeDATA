# 拾页星图 · 本地知识库（Folio Atlas）

一个离线运行、支持任意深度目录树、可搜索并支持多种 Windows 文件操作的个人知识库。

> “知屿”是项目初建时由 AI 拟定的工作名，并非 GitHub 原项目名称。本项目是按用户需求从零实现的轻量项目；自 1.2.0 起正式命名为“拾页星图（Folio Atlas）”。程序不依赖仓库文件夹名称：从 GitHub 默认克隆为 `LocalKnowledgeDATA`，或自行改名后均可运行。

## 快速开始（推荐：纯 Windows，无需 WSL）

1. 克隆或解压项目到任意本地目录，并在 Windows 资源管理器中打开该目录。
2. 双击 **`start-windows.vbs`**；它使用项目自带的便携 Python，在后台启动服务并打开浏览器。
3. 浏览器会自动打开 `http://127.0.0.1:8765`。
4. 不再使用时，双击 **`stop-windows.vbs`**。

每次成功启动都会同步生成项目根目录的固定文件 **`KNOWLEDGE_STRUCTURE.md`**。它是当前 `library/` 的完整目录树快照，供 AI 和人快速判断资料应放在哪里；始终覆盖同一路径且内容未变化时不改写，因此不会积累一批带日期或编号的旧文件。

`start-windows.bat` / `stop-windows.bat` 是会显示控制台信息的排错备用入口。纯 Windows 启动方式不要求电脑安装 WSL，也不要求预装 Python。

### 兼容保留的 WSL 启动方式

已有 WSL 的电脑仍可使用 `start-kb.vbs` / `stop-kb.vbs`；对应 `.bat` 文件用于显示排错过程。两套启动器不要同时运行，日常优先使用纯 Windows 版本。

> 不要直接双击 `static/index.html`。浏览器出于安全限制，普通 HTML 不能扫描本机文件夹或启动系统程序；一键启动器会启动仅监听本机的轻量服务，再打开页面。

## 添加资料（支持任意深度）

```text
library/
└─ 算法/                     ← 一级目录
   ├─ _分类.md               ← 可选：一级目录名称、图标和排序
   └─ 数论/                  ← 可继续嵌套
      ├─ _说明.md            ← 可选：本级目录名称、摘要和说明
      ├─ 质数/
      │  ├─ _说明.md
      │  ├─ 埃氏筛.html          ← 首选学习页
      │  ├─ 埃氏筛.md            ← Markdown 备用版
      │  └─ 埃氏筛.cpp           ← AC 代码或附件
      └─ 最大公约数/
         └─ 欧几里得.cpp
```

操作方法：

1. 在 `library` 中建立符合知识关系的目录树，层级没有固定上限。
2. 一级目录需要自定义图标或顺序时，添加 `_分类.md`。
3. 任意目录需要摘要、标签或悬浮说明时，添加 `_说明.md`。
4. 把资料放在最合适的目录中；页面只展示当前目录的直属子目录和直属文件。
5. 新题目或知识点优先同时保留精致 HTML 学习页与 Markdown 备用版。具体题目必须在两种版本中保留完整题面、输入、输出、数据范围和样例，再另列题目模型与精简题解；不能用题意摘要替代原题。AC 代码、PDF 等附件照常保留；存在 AC 代码时，HTML 还应展示完整代码和程序整体执行流程，同时保留已有关键函数讲解且避免重复。
6. 在 `_说明.md` 中用 `entry: 文件名.html` 指定首选入口；若省略，扫描器自动选择本目录按名称排序后的第一个 HTML。
7. 已打开的页面会在数秒内自动更新；结构发生变化时，`KNOWLEDGE_STRUCTURE.md` 也会按需原子更新，无需手工维护索引。

也可以把文件直接放进任意目录。目录说明属于目录节点；同级文件会显示在该目录的“直属文件”区域。

仓库自带“算法 / 数论 / 质数、最大公约数”多级验收示例，内容来自单元测试夹具，可用于检查逐级导航、面包屑和目录说明。个人新增资料默认由 `.gitignore` 排除，公开新目录前请先阅读 `docs/公开发布与隐私.md`。

## 页面能力

- 任意深度目录树、逐级进入和面包屑返回；
- 工具栏“结构总览”以右侧星图抽屉显示完整目录层级：首次打开默认展开全部目录，支持结构内搜索、折叠、展开当前位置和按需显示直属文件；选择目录后回到原有逐级浏览界面；
- 全库搜索目录名称、路径、说明、标签和文件名；
- 按根目录、子树文件类型和收藏筛选；
- 每级目录卡片都可显示本级 `_说明.md`；长说明可把鼠标移入悬浮窗并直接滚动；
- 进入具体题目目录后，首选 HTML 会显示为醒目的“打开学习笔记”入口；Markdown、CPP、PDF 等仍完整显示在直属文件列表；
- 浏览器查看、默认应用打开、选择应用打开，以及在资源管理器中定位文件；
- 自动检测目录变化并更新；
- 深色/浅色主题、响应式布局、键盘焦点和减少动画支持；
- 全部数据留在本机，服务只监听 `127.0.0.1`。

## 说明文件格式

```markdown
---
title: 显示名称
tags: [标签一, 标签二]
pinned: false
order: 100
summary: 卡片上显示的一句话摘要。
entry: 首选学习页.html
---

这里写本级目录的完整说明，会出现在桌面端悬浮窗和进入目录后的“当前目录”说明区中。
```

可用字段：

| 字段 | 作用 | 默认值 |
|---|---|---|
| `title` | 目录显示名称 | 文件夹名 |
| `tags` | 搜索与标签展示 | 空 |
| `pinned` | 是否优先排列 | `false` |
| `order` | 数字越小越靠前 | `9999` |
| `summary` | 目录卡片摘要 | 正文第一段 |
| `entry` | 本目录首选打开文件，只允许填写直属文件名 | 第一个 HTML；无 HTML 时为空 |

一级目录仍兼容 `_分类.md`，用于 `title`、`icon`、`order` 和 `summary`。如果一级目录同时存在 `_分类.md` 与 `_说明.md`，显示字段以 `_说明.md` 为准，图标等未覆盖字段继续使用 `_分类.md`。

## 文档与日志

- `docs/使用手册.md`：完整日常操作；
- `docs/HTML学习笔记设计规范.md`：HTML 学习页的设计、内容与验收标准；
- `KNOWLEDGE_STRUCTURE.md`：自动生成且固定覆盖的全库结构快照，优先供 AI 选址和人工总览（运行文件，不提交 Git）；
- `AI资料整理与放置指南.md`：未来 AI 先读结构快照，再按最小范围整理已有资料；
- `docs/维护与扩展.md`：配置、备份和二次开发；
- `docs/架构设计.md`：技术选型与模块说明；
- `docs/故障排查.md`：启动和文件打开问题；
- `docs/公开发布与隐私.md`：公开仓库的资料、截图、日志与归档边界；
- `CHANGELOG.md`：版本更新记录；
- `logs/server.log`：运行与索引日志，自动轮转，最多保留约 4 MB；

若服务未运行但刚刚人工修改了 `library/`，可在项目根目录执行 `python3 generate_structure.py`；纯 Windows 可执行 `runtime\windows-python\python.exe generate_structure.py`。脚本只刷新同一个快照文件。

## 当前限制与后续扩展

当前搜索目录标题、路径、说明、标签和文件名，不读取 PDF/Word 内文。以后可增加：

- SQLite FTS5 / Pagefind 全文索引；
- PDF、Office 文本提取与 OCR；
- 本地模型问答（RAG），并保留来源引用；
- 标签编辑器、批量导入、重复文件检测；
- 可选的局域网只读分享与身份验证。

这些能力都可以接在现有扫描器和 `/api/catalog` 之后，不需要重做目录结构。
